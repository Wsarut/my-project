Project Overview

เรียนรู้จากสิ่งที่เกิดขึ้นกับระบบ ไม่ใช่เพียงจำชื่อภัยคุกคาม

โครงการนี้จัดทำขึ้นเพื่อช่วยให้ผู้เรียนเข้าใจความสัมพันธ์ระหว่างพฤติกรรมผิดปกติ ผลกระทบที่ผู้ใช้งานมองเห็น และข้อมูลหลังบ้านที่ผู้ดูแลระบบใช้ตัดสินใจ เนื้อหาครอบคลุมเว็บไซต์ข่าวสาร ร้านค้าออนไลน์ และระบบจำหน่ายตั๋ว ซึ่งมีข้อมูลและความเสี่ยงต่างกันอย่างชัดเจน

ขอบเขตเพื่อการศึกษา: เว็บไซต์ บัญชีผู้ใช้ ข้อมูลลูกค้า คำสั่งซื้อ การชำระเงิน และบัตรเข้างานทั้งหมดในโครงการเป็นข้อมูลจำลอง ไม่มีการเชื่อมต่อธุรกรรมจริง และไม่ควรนำคำสั่งหรือแนวทางไปใช้กับระบบที่ไม่ได้รับอนุญาต

Security Fundamentals

เส้นทางจากความเข้าใจสู่การตัดสินใจ

ผู้เรียนสามารถเริ่มจากหลักการพื้นฐาน ทดลองสถานการณ์แบบมี Command Reference แล้วจึงเข้าสู่ Challenge Mode ที่ต้องอ่านอาการและเลือกแนวทางป้องกันด้วยตนเอง

  1. 01 / FUNDAMENTALS

    ทำความเข้าใจหลักการ

    เรียนรู้ข้อมูลที่ต้องปกป้อง การยืนยันตัวตน การตรวจสอบความถูกต้อง และวงจรตอบสนองต่อเหตุการณ์

    ดูเส้นทางการเรียนรู้
  2. 02 / SIMULATE

    ทดลองในระบบจำลอง

    สลับบทบาทระหว่างผู้โจมตีและผู้ป้องกัน พร้อมตรวจผลที่เกิดขึ้นทั้งบนหน้าเว็บไซต์และข้อมูลภายในระบบ

    เลือก Simulation
  3. 03 / RESPOND

    รับมือภายใต้ข้อจำกัด

    วิเคราะห์เว็บไซต์แบบสุ่ม ใช้คู่มือภาคสนาม ตรวจ DATA LINK และกู้คืนระบบภายในเวลาที่กำหนด

    เข้าสู่ Challenge Mode

Security Principles

มองความปลอดภัยผ่านคุณสมบัติของข้อมูล

สถานการณ์ในโครงการไม่ได้วัดเพียงว่าเว็บไซต์เปิดได้หรือไม่ แต่ชวนตรวจว่าข้อมูลถูกเปิดเผย ถูกเปลี่ยน หรือไม่พร้อมให้ผู้ใช้ที่ควรเข้าถึงหรือไม่

Confidentiality

ข้อมูลลูกค้า บัญชี และ session ต้องเข้าถึงได้เฉพาะบุคคลและระบบที่ได้รับอนุญาต

Integrity

เนื้อหา ราคา คำสั่งซื้อ และจำนวนตั๋วต้องตรวจสอบย้อนกลับและเทียบกับแหล่งข้อมูลที่เชื่อถือได้

Availability

ระบบต้องพร้อมให้ผู้ใช้ทั่วไปเข้าถึงได้ แม้เผชิญคำขอผิดปกติหรือเหตุการณ์ที่กระทบทรัพยากร

Primary References

เนื้อหาที่มีที่มาและตรวจสอบต่อได้

หลักการและคำอธิบายด้านความปลอดภัยของโครงการควรอ้างอิงจากมาตรฐานและแหล่งความรู้ขององค์กรต้นทาง ผู้เรียนสามารถใช้รายการต่อไปนี้เพื่อศึกษารายละเอียดเพิ่มเติม

NIST Cybersecurity Frameworkกรอบการจัดการความเสี่ยงและวงจรการดำเนินงานด้านความปลอดภัย↗ OWASP Top 10ความเสี่ยงสำคัญที่พบในการพัฒนาและใช้งานเว็บแอปพลิเคชัน↗ CISA Secure by Designแนวทางสร้างระบบที่ให้ความสำคัญกับความปลอดภัยตั้งแต่การออกแบบ↗ MITRE ATT&CKฐานความรู้เกี่ยวกับพฤติกรรมและเทคนิคที่ใช้ในเหตุการณ์ด้านความปลอดภัย↗
